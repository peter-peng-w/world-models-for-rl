# Figures and editable diagrams

All figures here are original conceptual illustrations, not reproductions of paper figures or empirical results.

- [World-model loop](world-model-loop.svg): experience, dynamics learning, and decisions.
- [Decision paths](decision-paths.svg): online trajectory optimization, imagination-based policy learning, and tree search.
- [Design space](design-space.svg): prediction targets versus model usage.
- [Editable Mermaid source](diagrams.md): flow diagrams that GitHub renders natively.

Regenerate the SVG figures with `python3 scripts/build_figures.py`. They use a fixed light background for legibility in either GitHub theme and contain accessible titles and descriptions.
