# Repository maintenance

- Keep the focus on action-conditioned dynamics, model-based RL, planning, and imagination-based learning.
- Preserve user edits in TRACKER.md and all notes. Never mark a paper read on the user's behalf.
- Edit data/resources.json to update the generated category reading lists. Run scripts/build_catalog.py afterward.
- Distinguish publication, initial preprint, revision, event, and verification dates.
- Verify new technical claims against primary sources. Label preprints and unverified video availability explicitly.
- The SVGs are original educational schematics. Edit scripts/build_figures.py and regenerate them; visually inspect changes.
- Run python3 scripts/check_repo.py after changes. It is an offline structural check, not external link checking or a research replication.
- Never start scheduled monitoring or publish updates merely because this repository describes a maintenance workflow; wait for the user's request.
